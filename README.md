# tf-04.js

Esse arquivo é só um compilado rápido de exemplos de funções em JavaScript.  
A ideia é mostrar, de forma simples e prática, como funções podem ser usadas em diferentes situações.

## O que tem dentro

1. **Função básica**  
   - Um exemplo clássico: recebe um nome e retorna uma saudação.

2. **Função guardada em constante**  
   - Mostra que dá pra salvar uma função dentro de uma variável/constante e usar depois.

3. **Função dentro de objeto (método)**  
   - Demonstra como colocar funções em objetos e chamá-las como métodos.

4. **Callback**  
   - Exemplo de passar uma função como argumento pra outra e ver ela sendo chamada.
